# Pitch Deck Structure Skill

> "Storytelling is the most powerful way to put ideas into the world." — Robert McKee

A purpose-built Codex skill for creating startup pitch deck skeletons focused on fundraising narrative, slide sequencing, and slide layouts. Trained on dozens of the best decks out there.

Use to turn messy context/thoughts into a clear pitch deck narrative structure for early stage (seed-B) fundraising. Give it context and data, pair with your own design system skills, and then hand it to a presentation-generation tool such as PowerPoint, Google Slides, Canva, Paper, Gamma, etc.

## Install

Copy the skill folder into your Codex skills directory:

```bash
mkdir -p ~/.codex/skills
cp -R pitch-deck-structure ~/.codex/skills/
```

Then invoke it in Codex:

```text
Use $pitch-deck-structure to create a pitch deck skeleton for a startup fundraising narrative.
```

## Contents

- `pitch-deck-structure/SKILL.md`: core workflow and output format
- `pitch-deck-structure/references/arcs.md`: narrative arcs by stage and company type
- `pitch-deck-structure/references/slide-patterns.md`: slide purposes, sequencing, and appendix guidance
- `pitch-deck-structure/references/layout-patterns.md`: layout and data-visualization patterns
